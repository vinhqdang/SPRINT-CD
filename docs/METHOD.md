# SPRINT-CD: method notes

This document states the constructions and guarantees precisely, and is
explicit about which claims are proved, which are checked numerically, and
which are assumptions the user must own.

---

## 1. The problem with monitoring

A conditional-independence test returns a p-value valid at the sample size it
was computed for. In a streaming setting the analyst naturally recomputes it
as data accumulate and stops when the answer looks settled. That stopping rule
is data-dependent, and the guarantee does not survive it: the probability that
a null p-value *ever* dips below `alpha` tends to one as monitoring continues.

Experiment 1 quantifies this on exactly the queries a discovery algorithm
issues: at `alpha = 0.05`, monitoring a null partial-correlation test drives
the Type-I error from a nominal 5% to roughly 34%.

An **e-process** for a null `H0` is a non-negative process `(E_t)` with
`E[E_tau] <= 1` for every stopping time `tau`. Ville's inequality gives

```
P( exists t : E_t >= 1/alpha ) <= alpha,
```

a bound that holds *uniformly in time*. Monitoring becomes free.

---

## 2. An exact e-process for linear-Gaussian conditional independence

Write the hypothesis `X_i indep X_j | X_S` in regression form

```
X_i = X_S' alpha + beta X_j + eps,     eps ~ N(0, sigma^2),
```

so under joint Gaussianity the null is `beta = 0` with nuisance
`(alpha, sigma)`.

Give the nuisance block the **right-Haar prior** `pi(alpha, sigma) ∝ 1/sigma`
under both hypotheses, and the tested coefficient the scale-matched prior
`beta | sigma ~ N(0, sigma^2 g)`. Integrating out all of `(alpha, beta, sigma)`
in closed form gives the Bayes factor

```
              -1/2                        -(n-p)/2
E_n = (1 + G)      * ( 1 - kappa * r_n^2 )
```

where, writing `S_xx, S_xy, S_yy` for the cross-products of the `X_S`-residualised
vectors,

```
p     = |S| + 1                     (nuisance dimension, intercept included)
G     = g * S_yy
kappa = G / (1 + G)
r_n^2 = S_xy^2 / (S_xx * S_yy)      (squared sample partial correlation)
```

Two consequences drive the whole design.

**(a) No per-hypothesis state.** `E_n` depends on the data only through
`(S_xx, S_xy, S_yy, n)`, and those are Schur complements of the running Gram
matrix. One `O(d^2)` sufficient statistic therefore serves the entire --
combinatorially large -- hypothesis family, and e-processes for hypotheses the
algorithm never examines cost nothing.

**(b) `g` must be fixed in advance.** A prior scale that adapts to the running
sample size destroys the martingale property. SPRINT-CD sets `g` from a
**warm-up prefix** that is then excluded from every e-process, which makes the
hyper-parameter legitimately data-independent.

### Validity

The prior is right-Haar for the amenable location-scale group
`x -> c(x + Z alpha)`, so the Bayes factor is a non-negative martingale in the
filtration generated by the maximal invariants, hence an e-process. Rather
than lean on that argument alone, calibration is verified by simulation:
monitoring after *every* observation over 3000 replications and 1500 time
points gives, against nominal `alpha`:

| `alpha` | 0.20 | 0.10 | 0.05 | 0.01 |
|---|---|---|---|---|
| `P(sup_t E_t >= 1/alpha)` | 0.149 | 0.076 | 0.041 | 0.008 |

Valid, and tight enough to retain power. The same check is run for both
universal-inference constructions in `tests/test_eprocess.py`.

### Block form

For E-ICP the tested object is a block of `q` coefficients. With
`beta | sigma ~ N(0, sigma^2 g I_q)`,

```
E_n = |I_q + g S_ww|^{-1/2} * ( S_tt / (S_tt - S_wt' (S_ww + I_q/g)^{-1} S_wt) )^{(n-p)/2}
```

which reduces to the scalar form at `q = 1`.

## 3. Accepting independence: the hard direction

E-processes accumulate evidence *against* a null. Removing an edge requires
the opposite: positive evidence *for* independence. This is the main technical
obstacle, and it is worth being blunt that no test can certify an exactly-zero
coefficient from finite data.

SPRINT-CD uses an **equivalence-testing** formulation. Inverting the family of
e-values `{E_n(b)}` -- testing `beta = b` amounts to replacing `x` by
`x - b*y` -- yields a closed-form anytime-valid confidence sequence:

```
CS_n = beta_hat  ±  (1 / S_yy) * sqrt( tau * (S_xx*S_yy - S_xy^2) / (1 - tau) )

beta_hat = S_xy / S_yy
tau      = [ 1 - (alpha / sqrt(1+G))^{2/(n-p)} ] / kappa
```

The interval is non-degenerate once `tau < 1`, and `tau` decays like
`log(n)/n`, giving the `sqrt(log n / n)` width characteristic of confidence
sequences. Because every `E_n(b)` is an e-process, the interval covers `beta`
at *all* sample sizes simultaneously with probability `1 - alpha`.

An edge is removed when this interval fits entirely inside a **region of
practical equivalence** `(-delta, delta)`.

### The ROPE lives on the partial-correlation scale

`beta_{ij.S} = rho_{ij.S} * sigma_{i|S} / sigma_{j|S}`, so a raw
coefficient-scale region is not scale-free across conditioning sets. On a
strongly connected chain the ratio reaches 1.7, inflating the sample size
needed to delete an edge by the same factor -- and producing the
counter-intuitive behaviour that a *stronger* SEM coefficient makes deletion
*slower*. SPRINT-CD therefore specifies `delta` on the partial-correlation
scale and converts it using warm-up estimates of the ratio. Those estimates
are fixed constants as far as every e-process is concerned, so validity is
untouched.

## 4. Lifting single-test validity to the whole graph

A constraint-based algorithm chooses *which* hypothesis to examine next based
on the graph estimated so far -- that is, on the data. Validity cannot be
recovered afterwards by correcting for "the tests that were run", because
their number and identity are themselves random.

SPRINT-CD budgets over the entire *potential* family, fixed before any data
arrive:

```
H_k = { (i, j, S) : i < j,  S subset of V \ {i,j},  |S| <= k }
```

Weights `w(i,j,S)` summing to one are assigned in advance -- decaying
geometrically in `|S|`, since separating sets predominantly live at low order
-- and hypothesis `(i,j,S)` is decided at level `alpha * w(i,j,S)`. A union
bound over `H_k` combined with Ville's inequality gives, for every stopping
time simultaneously,

```
P( exists (i,j,S) in H_k true and rejected ) <= sum alpha * w(i,j,S) = alpha.
```

The bound never references which hypotheses were examined, so the adaptive,
graph-dependent enumeration of conditioning sets costs nothing: restricting
the search to PC neighbourhoods is a pure computational saving that can only
make the procedure more conservative.

**Budget recycling is not sound.** Reallocating a resolved hypothesis's weight
to unresolved ones is data-dependent and breaks the union bound. This
implementation uses fixed weights only. `e_bh` is provided as the sound way to
trade the conservatism of a union bound for a false-discovery-rate criterion;
it is valid under arbitrary dependence, which matters because e-processes for
overlapping conditioning sets share data.

## 5. The guarantee

Let `tau` be **any** stopping time, including one chosen by looking at the
output. Assume

1. a linear-Gaussian SEM (and causal sufficiency, for SPRINT-CD);
2. **`delta`-strong faithfulness**: `|rho_{ij.S}| >= delta` for every adjacent
   pair `(i,j)` and every `S` with `|S| <= k`.

Then

```
P( exists tau :  a true edge is absent from G_tau
                 or a true independence is certified dependent )  <=  alpha.
```

*Proof sketch.* Falsely deleting an adjacent pair requires some confidence
sequence for `beta_{ij.S}` to have excluded its true value -- which has
modulus at least `delta` while the certificate demands the interval sit inside
`(-delta, delta)` -- an event of probability at most `alpha_del * w(i,j,S)`
uniformly in time by Ville. Falsely claiming dependence requires an e-process
under its own null to cross `1/(alpha_dep * w(i,j,S))`, likewise bounded.
Summing over the fixed family and the two budgets gives
`alpha_del + alpha_dep = alpha`. On the complement, every retained edge set is
a correct superset and every recorded separating set genuine, so all
v-structures are correctly oriented; Meek's rules are deterministic and add no
error. ∎

### What is *not* claimed

The guarantee is deliberately **one-sided on the skeleton**. At small `t`
nothing has been certified and the output is a dense superset of the truth.
What is controlled uniformly in time is the *removal* of true edges and the
*assertion* of false dependence -- the errors that are irreversible in a
streaming setting. Extra edges are the price, and Experiment 2 plots both
sides of that trade.

### `delta`-strong faithfulness is a real restriction

This is the assumption most likely to fail in practice, and the experiments
measure it rather than presume it. In random 7-variable graphs with one latent
variable marginalised out, only about a quarter of instances satisfy it at
`delta = 0.15`; the median smallest partial correlation over true adjacencies
is around 0.03. Experiment 4 therefore stratifies: where the premise holds the
false-deletion rate is 0 out of 20 against a budget of 0.1; where it fails the
rate is 0.80. Deleting an edge whose partial correlation genuinely lies inside
the equivalence region is correct behaviour by construction, not a failure of
calibration -- but it does mean `delta` must be chosen with the application's
smallest scientifically meaningful effect in mind.

## 6. Latent confounders

SPRINT-FCI reuses the machinery and returns a PAG. Two restrictions keep the
guarantee intact:

* Possible-D-SEP refinement runs only over conditioning sets of size at most
  `k`, so every hypothesis it touches already lies inside the budgeted family.
* Orientation uses R1-R4. R5-R7 (selection bias) and R8-R10 (tail
  completeness) are omitted. Every mark written is entailed, so the PAG is
  **sound but not guaranteed maximally informative**.

## 7. E-ICP

Invariant Causal Prediction retains candidate sets `S` under which the
conditional law of `Y` given `X_S` is invariant across environments, and
returns the intersection. Its subset guarantee is fixed-sample, and is void if
environments are accumulated and monitored.

E-ICP expresses invariance as the null that a block of coefficients vanishes,

```
Y = mu + X_S' gamma + sum_e delta_e D_e + sum_e sum_{j in S} theta_ej D_e X_j + eps,
```

and tests that block with the block e-process of §2. With fixed weights `w(S)`,
a union bound gives `P(exists t : S* rejected) <= alpha`, hence

```
S_hat_t = intersection of non-rejected S  ⊆  S*   simultaneously at all t.
```

**Scope.** The tested block captures conditional-mean shifts, including
environment-specific slopes. A shift in noise *variance* alone leaves the block
at zero and goes undetected -- the same limitation as mean-based ICP variants.
Controlling anytime-valid family-wise error also sidesteps the observation of
Li and Goeman (2024) that FDR sits awkwardly with ICP's intersection output.

---

## 8. Terminology: "anytime FCI" is a different thing

"Anytime FCI" (Spirtes, 2001) is a *computational* property: the outer loop
over conditioning-set sizes may be interrupted and still return a sound graph.
"Anytime-valid" here is an *inferential* property: time-uniform Type-I error
control at data-dependent stopping times. The two are unrelated, and the
resemblance in name is the likeliest source of confusion about what this work
claims.

---

## 9. Relation to existing work

The components exist separately; the assembly is what is new here.

* **Sequential CI tests** (testing-by-betting and kernelised variants) answer a
  *single* hypothesis. They are not embedded in a graph procedure, and the
  Model-X constructions need the conditional law of `X` given `Z`, which is
  typically unavailable in discovery.
* **Whole-graph error control** (e.g. PC with edge-wise p-values and
  Benjamini-Yekutieli) is fixed-`n` and uses classical corrections; it offers
  no stopping-time guarantee.
* **E-values inside PC** have been used for causal discovery under costly or
  missing data on a *fixed* dataset -- a different objective from streaming,
  time-uniform whole-graph control.
* **ICP error control** is an active topic, but the invariance test has not
  been given an e-process form.

What SPRINT-CD adds is the combination: an e-process CI oracle, a
confidence-sequence device for the acceptance direction, and the fixed-family
budgeting argument that lifts single-test validity to a whole graph under
arbitrary stopping.
